Selected Work Manager

Upload several project screenshots and publish new cards to the Selected Work section of your portfolio.

This is a separate helper page. It uploads image files to your GitHub repository and appends project cards to index.html.

1. Connect your GitHub repository

Create a fine-grained token for this repository with Contents: Read and write. Do not put your token in your website code or share it with anyone. This page does not save it to local storage.

2. Add screenshots

Drag and drop multiple screenshots here or click to choose PNG, JPG, WEBP, or GIF files
Ready. Connect to GitHub, then add your screenshots.

Before publishing

Important: This tool adds new project cards; it does not delete or replace your existing cards. Check that screenshots contain no private information, trainee details, or confidential records.

Each screenshot becomes one project card. You can edit its title, description, category, status, and technologies before publishing. GitHub Pages may take a short time to show the update.
